In my sophomore year computer systems class, I was tasked with building a document management system in C that could efficiently store and manipulate structured text. I made a modular document processing engine that supports operations such as adding and removing paragraphs and lines, as well as advanced text features like search-and-replace and highlighting. I learned how to design and implement low-level data structures, manage memory carefully, and work extensively with pointers and string manipulation functions. I also gained experience with file I/O by implementing functionality to load from and save documents to external files while handling edge cases and input validation. This project strengthened my understanding of systems programming concepts and improved my ability to write reliable, efficient, and maintainable C code.
